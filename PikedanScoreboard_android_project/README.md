皮克蛋计分器 · 安卓 APK 打包工程
================================

方式一：GitHub 云端打包（推荐，无需装任何软件）
------------------------------------------------
1. 在 GitHub 新建一个仓库，把本工程所有文件上传（保持目录结构不变）。
2. 上传后 Actions 会自动开始构建（或进入 Actions 页面手动 Run workflow）。
3. 构建完成后，在 Actions 运行记录页面底部下载构件
   「pikedan-scoreboard-apk」，里面的 app-debug.apk 就是安装包。
4. 把 apk 传到安卓设备安装即可（允许“安装未知来源应用”）。

方式二：Android Studio 本地打包
--------------------------------
1. 安装 Android Studio，选择 Open 打开本工程目录。
2. 等待 Gradle 同步完成（自动下载依赖，需联网）。
3. Build → Build Bundle(s) / APK(s) → Build APK(s)。
4. 安装包位置：app/build/outputs/apk/debug/app-debug.apk。

装机后必做（开机自启动）
------------------------
1. 打开一次应用（解锁语音、完成初始化）。
2. 到系统 设置 → 应用管理 → 皮克蛋计分器：
   - 开启「自启动」（小米叫自启动管理，华为/OPPO/vivo 类似）；
   - 电池策略设为「无限制 / 不优化」，防止后台被杀。
3. 重启设备验证：开机后会自动进入计分器。

语音播报说明
------------
APK 内使用系统 TTS 语音合成，依赖设备装有中文语音引擎：
- 谷歌系设备：需安装「Google 文字转语音引擎」并下载中文语音包；
- 国产 ROM 一般自带讯飞/小爱等 TTS 引擎，通常直接可用。
若按下 + 出现“🔊 X比X”提示但没声音，请检查：
静音开关、系统音量、TTS 引擎的中文语音包。
